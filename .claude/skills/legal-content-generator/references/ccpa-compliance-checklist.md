# CCPA/CPRA Compliance Checklist

## Overview

The California Consumer Privacy Act (CCPA), as amended by the California Privacy Rights Act (CPRA), applies to for-profit businesses that:
- Have annual gross revenue over $25 million, OR
- Buy, sell, or share personal information of 100,000+ California residents, OR
- Derive 50%+ of annual revenue from selling/sharing California residents' personal information

## Consumer Rights

### Right to Know (Civil Code 1798.100)
- [ ] Disclose categories of personal information collected
- [ ] Disclose purposes for collection
- [ ] Disclose categories of sources
- [ ] Disclose categories of third parties shared with
- [ ] Disclose specific pieces of personal information collected
- [ ] Process exists for consumer requests
- [ ] Response within 45 days (extendable to 90)
- [ ] Free disclosure twice per 12-month period

### Right to Delete (Civil Code 1798.105)
- [ ] Process for deletion requests
- [ ] Exceptions documented:
  - [ ] Complete transactions
  - [ ] Security purposes
  - [ ] Debug/repair
  - [ ] Exercise free speech
  - [ ] Comply with legal obligations
  - [ ] Internal uses consistent with expectations
  - [ ] Public interest research
- [ ] Notify service providers of deletion
- [ ] Response within 45 days

### Right to Correct (Civil Code 1798.106)
- [ ] Process for correction requests
- [ ] Consider totality of circumstances
- [ ] Document correction or denial
- [ ] Response within 45 days

### Right to Opt-Out of Sale/Sharing (Civil Code 1798.120)
- [ ] "Do Not Sell or Share My Personal Information" link
- [ ] Link on homepage
- [ ] Opt-out honored within 15 business days
- [ ] No re-asking for opt-in for 12 months
- [ ] Service providers notified
- [ ] Global Privacy Control honored

### Right to Limit Use of Sensitive Personal Information (Civil Code 1798.121)
- [ ] "Limit the Use of My Sensitive Personal Information" link (if applicable)
- [ ] Link on homepage (if applicable)
- [ ] Limits honored promptly
- [ ] Service providers notified

### Right to Non-Discrimination (Civil Code 1798.125)
- [ ] No denial of goods/services for exercising rights
- [ ] No different price/quality for exercising rights
- [ ] Financial incentive programs disclosed
- [ ] Incentives proportional to value of data

### Right to Data Portability (Civil Code 1798.130)
- [ ] Portable format available
- [ ] Machine-readable format
- [ ] Technical format specified

## Privacy Notice Requirements (Civil Code 1798.100)

### General Requirements
- [ ] Available at or before point of collection
- [ ] Updated at least annually
- [ ] Accessible to consumers with disabilities
- [ ] Available in languages used by business

### Required Disclosures
- [ ] Categories of personal information collected in past 12 months
- [ ] Categories of sensitive personal information collected
- [ ] Purposes for collecting each category
- [ ] Categories of sources for each category
- [ ] Business or commercial purpose for collection
- [ ] Categories of third parties shared with
- [ ] Whether personal information is sold or shared
- [ ] Length of time each category is retained

### Notice at Collection
- [ ] Categories to be collected
- [ ] Purposes for each category
- [ ] Whether sold or shared
- [ ] Retention period
- [ ] Link to full privacy policy

## Categories of Personal Information

### Standard Categories (1798.140(v))
- [ ] Identifiers (name, email, IP address)
- [ ] Customer records (address, phone, financial info)
- [ ] Protected characteristics (age, race, gender)
- [ ] Commercial information (purchase history)
- [ ] Biometric information
- [ ] Internet/network activity
- [ ] Geolocation data
- [ ] Sensory data (audio, video)
- [ ] Professional/employment info
- [ ] Education information
- [ ] Inferences drawn from above

### Sensitive Personal Information (1798.140(ae))
- [ ] Social Security number
- [ ] Driver's license/state ID/passport
- [ ] Account login with required security code
- [ ] Financial account with access code
- [ ] Precise geolocation
- [ ] Racial/ethnic origin
- [ ] Religious/philosophical beliefs
- [ ] Union membership
- [ ] Contents of mail/email/text
- [ ] Genetic data
- [ ] Biometric data for ID
- [ ] Health information
- [ ] Sex life/sexual orientation

## Service Provider Requirements

### Contract Requirements (1798.140(ag))
- [ ] Written contract with service providers
- [ ] Specifies permitted uses
- [ ] Prohibits retention beyond purpose
- [ ] Prohibits sale of personal information
- [ ] Prohibits use outside direct business relationship
- [ ] Requires notification of consumer requests
- [ ] Requires compliance with CCPA
- [ ] Permits monitoring of compliance
- [ ] Requires notification if unable to comply

### Contractor Requirements
- [ ] Certification of understanding
- [ ] Compliance with restrictions
- [ ] Same requirements as service providers

## Request Handling

### Verification Requirements
- [ ] Reasonable method to verify identity
- [ ] Match information already maintained
- [ ] Additional verification for sensitive data
- [ ] Document verification process

### Response Requirements
- [ ] Acknowledge within 10 business days
- [ ] Respond within 45 days
- [ ] One 45-day extension allowed with notice
- [ ] Provide reason if request denied
- [ ] Explain how to appeal

### Methods of Submission
- [ ] Toll-free number available
- [ ] Website method available
- [ ] Email address available (if collects email)
- [ ] Physical mail option (if applicable)

## Minors (Civil Code 1798.120)

### Under 16
- [ ] No sale/sharing without opt-in consent
- [ ] Parent/guardian consent for under 13
- [ ] Teen consent for 13-15

### Consent Process
- [ ] Clear opt-in mechanism
- [ ] Cannot rely on default settings
- [ ] Document consent obtained

## Record Keeping Requirements

### Training Records
- [ ] Staff training documented
- [ ] Training includes CCPA requirements
- [ ] Training updated as needed

### Request Records
- [ ] Log of requests received
- [ ] Response times documented
- [ ] Request types tracked
- [ ] Statistics available for CPPA request

### Metrics Disclosure (if >10M consumers)
- [ ] Number of requests to know
- [ ] Number of requests to delete
- [ ] Number of requests to opt-out
- [ ] Median response time
- [ ] Published in privacy policy

## Privacy Policy Checklist

### Format
- [ ] Conspicuous link on homepage
- [ ] "Privacy Policy" or similar language
- [ ] Updated within past 12 months
- [ ] Date of last update displayed

### Content
- [ ] Description of consumer rights
- [ ] How to submit requests
- [ ] Categories collected (past 12 months)
- [ ] Sources of personal information
- [ ] Business purposes for collection
- [ ] Categories of third parties
- [ ] Disclosure of sale/sharing
- [ ] Retention periods
- [ ] Financial incentive program details (if any)

### Links Required
- [ ] "Do Not Sell or Share My Personal Information"
- [ ] "Limit the Use of My Sensitive Personal Information" (if applicable)
- [ ] Link to submit requests

## CPRA Updates (Effective 2023+)

### New Requirements
- [ ] Right to correct inaccuracies
- [ ] Right to limit sensitive personal information use
- [ ] Purpose limitation principle
- [ ] Storage limitation principle
- [ ] Data minimization principle
- [ ] Risk assessments for high-risk processing
- [ ] Cybersecurity audits (regulations pending)
- [ ] Automated decision-making disclosures

### California Privacy Protection Agency
- [ ] Monitor for new regulations
- [ ] Respond to CPPA inquiries
- [ ] Cooperate with investigations

## Penalties

### Civil Penalties
- Up to $2,500 per violation
- Up to $7,500 per intentional violation
- $7,500 per violation involving minors

### Private Right of Action
- Data breaches only
- $100-$750 per consumer per incident
- Or actual damages if greater
- Injunctive relief
- 30-day cure period
