# GDPR Compliance Checklist

## Overview

The General Data Protection Regulation (GDPR) applies to organizations that:
- Are established in the EU/EEA, OR
- Offer goods/services to EU/EEA residents, OR
- Monitor behavior of EU/EEA residents

## Key Principles (Article 5)

### Lawfulness, Fairness, and Transparency
- [ ] Processing has a lawful basis
- [ ] Data subjects are informed about processing
- [ ] Privacy policy is clear and accessible

### Purpose Limitation
- [ ] Purposes are specified and documented
- [ ] Data not used for incompatible purposes
- [ ] New purposes require new consent/legal basis

### Data Minimization
- [ ] Only necessary data is collected
- [ ] Data collection is proportionate to purpose
- [ ] Regular review of data collected

### Accuracy
- [ ] Data is accurate and up-to-date
- [ ] Processes exist to correct inaccuracies
- [ ] Users can update their data

### Storage Limitation
- [ ] Retention periods are defined
- [ ] Data is deleted when no longer needed
- [ ] Retention schedule is documented

### Integrity and Confidentiality
- [ ] Appropriate security measures in place
- [ ] Access controls implemented
- [ ] Encryption used where appropriate

### Accountability
- [ ] Compliance can be demonstrated
- [ ] Records of processing maintained
- [ ] Policies and procedures documented

## Lawful Bases for Processing (Article 6)

### Consent
- [ ] Consent is freely given
- [ ] Consent is specific and informed
- [ ] Consent is unambiguous
- [ ] Consent can be withdrawn easily
- [ ] Records of consent maintained

### Contract
- [ ] Processing necessary for contract performance
- [ ] Processing necessary for pre-contract steps
- [ ] Documented contractual necessity

### Legal Obligation
- [ ] Specific legal requirement identified
- [ ] Processing limited to what's required
- [ ] Documentation of legal basis

### Vital Interests
- [ ] Life-or-death situations only
- [ ] No other lawful basis available
- [ ] Documented justification

### Public Interest
- [ ] Official authority or public task
- [ ] Basis in law
- [ ] Documented justification

### Legitimate Interests
- [ ] Legitimate interest identified
- [ ] Balancing test performed
- [ ] Data subject interests considered
- [ ] Documentation maintained

## Data Subject Rights (Articles 12-23)

### Right to Information (Articles 13-14)
- [ ] Privacy notice provided at collection
- [ ] Information clear and accessible
- [ ] All required information included:
  - [ ] Identity and contact details
  - [ ] DPO contact (if applicable)
  - [ ] Purposes and legal basis
  - [ ] Categories of recipients
  - [ ] International transfer info
  - [ ] Retention period
  - [ ] Data subject rights
  - [ ] Right to withdraw consent
  - [ ] Right to lodge complaint
  - [ ] Source of data (if not from subject)
  - [ ] Automated decision-making info

### Right of Access (Article 15)
- [ ] Process for handling access requests
- [ ] Response within one month
- [ ] No fee for first copy
- [ ] Format of response defined

### Right to Rectification (Article 16)
- [ ] Process for correction requests
- [ ] Response within one month
- [ ] Third parties notified of corrections

### Right to Erasure (Article 17)
- [ ] Process for deletion requests
- [ ] Criteria for erasure documented:
  - [ ] Data no longer necessary
  - [ ] Consent withdrawn
  - [ ] Objection to processing
  - [ ] Unlawful processing
  - [ ] Legal obligation
- [ ] Exceptions documented
- [ ] Third parties notified

### Right to Restriction (Article 18)
- [ ] Process for restriction requests
- [ ] Criteria documented
- [ ] Restricted data marked

### Right to Data Portability (Article 20)
- [ ] Process for portability requests
- [ ] Machine-readable format defined
- [ ] Direct transmission where feasible

### Right to Object (Article 21)
- [ ] Process for objection requests
- [ ] Marketing objections honored
- [ ] Legitimate interest objections handled

### Automated Decision-Making (Article 22)
- [ ] Automated decisions identified
- [ ] Human intervention available
- [ ] Explanation of logic provided
- [ ] Safeguards implemented

## International Transfers (Chapter V)

### Adequacy Decisions
- [ ] Transfer to adequate countries identified
- [ ] Current adequacy decisions verified

### Standard Contractual Clauses
- [ ] SCCs in place for transfers
- [ ] Appropriate module used
- [ ] Supplementary measures assessed

### Binding Corporate Rules
- [ ] BCRs approved (if applicable)
- [ ] Implementation documented

### Derogations
- [ ] Explicit consent obtained
- [ ] Contractual necessity documented
- [ ] Other derogations documented

## Security Requirements (Article 32)

### Technical Measures
- [ ] Encryption of personal data
- [ ] Pseudonymization where appropriate
- [ ] Confidentiality ensured
- [ ] Integrity ensured
- [ ] Availability ensured
- [ ] Resilience of systems
- [ ] Ability to restore data
- [ ] Regular testing of security

### Organizational Measures
- [ ] Security policies in place
- [ ] Staff training conducted
- [ ] Access controls implemented
- [ ] Incident response procedures
- [ ] Vendor security assessed

## Breach Notification (Articles 33-34)

### Authority Notification
- [ ] 72-hour notification process
- [ ] Information to include documented
- [ ] Record-keeping for breaches
- [ ] Risk assessment process

### Data Subject Notification
- [ ] High-risk breach notification process
- [ ] Communication methods defined
- [ ] Exemptions documented

## Data Protection Impact Assessment (Article 35)

### When Required
- [ ] High-risk processing identified
- [ ] New technologies assessed
- [ ] Systematic monitoring assessed
- [ ] Large-scale processing assessed

### DPIA Content
- [ ] Systematic description of processing
- [ ] Assessment of necessity
- [ ] Assessment of proportionality
- [ ] Risk assessment to rights
- [ ] Measures to address risks

## Records of Processing (Article 30)

### Controller Records
- [ ] Name and contact details
- [ ] Joint controller details (if applicable)
- [ ] DPO details (if applicable)
- [ ] Purposes of processing
- [ ] Categories of data subjects
- [ ] Categories of personal data
- [ ] Categories of recipients
- [ ] International transfers
- [ ] Retention periods
- [ ] Security measures description

### Processor Records
- [ ] Name and contact details
- [ ] Categories of processing
- [ ] International transfers
- [ ] Security measures description

## Data Protection Officer (Articles 37-39)

### DPO Required When
- [ ] Public authority (except courts)
- [ ] Core activities require monitoring
- [ ] Large-scale special category processing

### DPO Requirements
- [ ] Expert knowledge of data protection
- [ ] Independent in performing tasks
- [ ] Reports to highest management
- [ ] Contact details published
- [ ] Contact details provided to supervisory authority
