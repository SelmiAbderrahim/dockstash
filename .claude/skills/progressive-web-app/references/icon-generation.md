# Icon Generation - Deep Dive

## Overview

ServerlessBase uses `@vite-pwa/assets-generator` to generate all PWA icons from a single SVG source. The configuration is at `client/pwa-assets.config.ts`.

## Configuration

```typescript
// client/pwa-assets.config.ts
import { defineConfig, minimal2023Preset } from '@vite-pwa/assets-generator/config';

export default defineConfig({
  headLinkOptions: {
    preset: '2023',
  },
  preset: {
    ...minimal2023Preset,
    maskable: {
      sizes: [512],
      resizeOptions: {
        background: '#0f172a',  // Dark blue (matches theme_color)
      },
    },
    apple: {
      sizes: [180],
      resizeOptions: {
        background: '#ffffff',  // White for Apple touch icon
      },
    },
  },
  images: ['public/branding/logo-icon.svg'],  // SOURCE FILE
});
```

## Source Image Requirements

| Requirement | Value |
|-------------|-------|
| Format | SVG (vector, scales cleanly) |
| Location | `client/public/branding/logo-icon.svg` |
| Minimum dimensions | 512x512px viewport |
| Safe zone | Content within center 80% circle (for maskable) |
| Transparency | Supported (transparent areas filled with `background` color for maskable/apple) |

**NEVER use PNG/JPG as source.** SVG ensures crisp icons at all densities.

## Generated Output Files

| File | Size | Purpose |
|------|------|---------|
| `public/pwa-64x64.png` | 64x64 | Notification badge, favicon |
| `public/pwa-192x192.png` | 192x192 | Standard icon, shortcut icons |
| `public/pwa-512x512.png` | 512x512 | Splash screen, install dialog |
| `public/maskable-icon-512x512.png` | 512x512 | Android adaptive icon (with `#0f172a` background) |
| `public/apple-touch-icon-180x180.png` | 180x180 | iOS home screen icon (with `#ffffff` background) |

## Maskable Icon Safe Zone

Android adaptive icons can be displayed in various shapes (circle, rounded square, squircle). The maskable icon MUST keep all important content within the center 80% circle:

```
┌──────────────────────┐
│                      │
│   ┌──────────────┐   │
│   │              │   │
│   │   Content    │   │  ← 80% inner safe zone
│   │   goes here  │   │
│   │              │   │
│   └──────────────┘   │
│                      │
└──────────────────────┘  ← Full 512x512 canvas
```

Content outside the safe zone may be clipped by the device.

## How Icons Flow to Manifest

The web manifest in `vite.config.mjs` references the generated icons:

```javascript
icons: [
  { src: 'pwa-64x64.png',           sizes: '64x64',   type: 'image/png' },
  { src: 'pwa-192x192.png',         sizes: '192x192', type: 'image/png' },
  { src: 'pwa-512x512.png',         sizes: '512x512', type: 'image/png' },
  { src: 'maskable-icon-512x512.png', sizes: '512x512', type: 'image/png', purpose: 'maskable' },
]
```

The HTML `<head>` in `client/index.html` includes:
```html
<link rel="apple-touch-icon" href="/apple-touch-icon-180x180.png" />
```

## How Icons Flow to Android TWA

The TWA at `mobile/android/twa-manifest.json` references icons by URL:

```json
{
  "iconUrl": "https://serverlessbase.com/pwa-512x512.png",
  "maskableIconUrl": "https://serverlessbase.com/maskable-icon-512x512.png"
}
```

The Android app also has launcher icons at multiple densities in `mipmap-*/ic_launcher.png`. These are generated separately (not by `@vite-pwa/assets-generator`) and must match the web icons visually.

| Density | Size | File |
|---------|------|------|
| mdpi | 48x48 | `app/src/main/res/mipmap-mdpi/ic_launcher.png` |
| hdpi | 72x72 | `app/src/main/res/mipmap-hdpi/ic_launcher.png` |
| xhdpi | 96x96 | `app/src/main/res/mipmap-xhdpi/ic_launcher.png` |
| xxhdpi | 144x144 | `app/src/main/res/mipmap-xxhdpi/ic_launcher.png` |
| xxxhdpi | 192x192 | `app/src/main/res/mipmap-xxxhdpi/ic_launcher.png` |

## Running Icon Generation

```bash
# Inside Docker container
docker exec -it serverless-client npx @vite-pwa/assets-generator

# Or via npm script
docker exec -it serverless-client npm run generate-pwa-icons

# Watch mode (regenerates on SVG changes)
docker exec -it serverless-client npm run generate-pwa-icons:watch
```

## iOS Splash Screens

The `index.html` includes splash screen `<link>` tags for various iOS device sizes. These are static PNG files in `client/public/` (not generated by the assets generator):

```html
<!-- Example splash screen links in index.html -->
<link rel="apple-touch-startup-image" href="/splash/apple-splash-2048-2732.png" ... />
<link rel="apple-touch-startup-image" href="/splash/apple-splash-1668-2388.png" ... />
<!-- ... 9 total variants -->
```

## When to Regenerate

| Change | Action |
|--------|--------|
| Updated logo SVG | Run `generate-pwa-icons` |
| Changed `theme_color` | Update `maskable.resizeOptions.background` in config, regenerate |
| Changed Apple background | Update `apple.resizeOptions.background` in config, regenerate |
| Added new icon size | Add to `preset` in config, regenerate |
| New Android density needed | Manually resize from 512px source (not automated) |

## Troubleshooting

| Issue | Fix |
|-------|-----|
| Icons look blurry | Ensure source is SVG, not raster PNG/JPG |
| Maskable icon content clipped | Move content inside 80% safe zone |
| Apple icon has wrong background | Check `apple.resizeOptions.background` in config |
| Generation fails | Verify `public/branding/logo-icon.svg` exists and is valid SVG |
| Android icons not matching web | Regenerate Android mipmap icons from same source |
