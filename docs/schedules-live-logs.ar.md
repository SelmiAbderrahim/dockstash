# الجداول والسجلات المباشرة

يدير Dockstash مهام النسخ الاحتياطي / التقليم / الفحص / تدريب الاستعادة على
جداول — عبر طابور متسلسل يضمن **مهمة واحدة لكل مستودع في وقت واحد**.

## أنواع الجداول

| النوع | الوظيفة |
|---|---|
| `backup` | يبث نسخ قواعد البيانات وينسخ المسارات/التكوينات. |
| `prune` | يشغل `restic forget --prune` وفق سياسة الاحتفاظ. |
| `check` | يشغل `restic check` — السلامة الهيكلية للمستودع. |
| `drill` | يستعيد أحدث لقطة إلى مساحة عمل ويقارنها. |

## مهمة واحدة لكل مستودع دائماً

المستودع يشغل مهمة واحدة فقط في المرة. جدولان يتفعلان معاً على نفس المستودع
يُنفذان بالتسلسل. المستودعات المختلفة تعمل بالتوازي.

## تعيين الاحتفاظ إلى `forget`

```
retention.keepDaily   → --keep-daily <n>
retention.keepWeekly  → --keep-weekly <n>
retention.keepMonthly → --keep-monthly <n>
```

## السجلات المباشرة

كل مهمة تبث خرج restic عبر Socket.IO على namespace `/scheduler`. انضم إلى
غرفة المهمة برمز JWT الخاص بك — يمكنك الانضمام فقط لمهامك.

## الاسترداد

بعد تعطل، تكتشف المحاولة التالية القفل المتروك وتشغل `restic unlock` بأمان.
