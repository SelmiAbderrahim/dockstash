# استخدام لوحة التحكم

يمنحك Dockstash أربع شاشات ومعالج إعداد لمرة واحدة. كل شاشة لها إجراء أساسي واحد.

## معالج الإعداد (أول تشغيل)
1. **خادم التخزين** — الصق مضيف و مستخدم ومنفذ ومفتاح SSH.
2. **كلمة مرور التشفير** — تُعرض مرة واحدة فقط. انسخها فوراً إلى مدير كلمات المرور.
3. **التأكيد** — ضع علامة "حفظتها — فقدانها يعني أن المستودعات غير قابلة للاسترداد" لتفعيل زر **تم**.

فقدان كلمة المرور = مستودعات لا يمكن فكّ تشفيرها.

## المشاريع
كل مجلد ضمن `/var/www` يظهر تلقائياً كبطاقة. إجراء أساسي واحد: **نسخ احتياطي الآن** مع بث مباشر لمخرجات restic.

## تفاصيل المشروع
ثلاثة تبويبات محفوظة في `?tab=`:
- **الخطة** — بدّل الملفات وقواعد البيانات و Traefik.
- **الجدولة** — يومياً / أسبوعياً / cron مخصص مع تحقق فوري.
- **تمرين الاسترجاع** — يعرض حالة آخر تمرين استرجاع (pass/fail).

## اللقطات
اختر مشروعاً، اختر نقطة استرجاع، ثم **استرجاع**. حوار تأكيد مطبوع يشترط كتابة اسم المشروع بدقة. الوضع الافتراضي "استرجاع إلى موقع جديد"؛ الاستبدال خيار صريح.

## الإعدادات
ثلاثة تبويبات في `?tab=`: التخزين، الاحتفاظ، كلمة مرور التشفير (تدوير مع تأكيد الحفظ).
