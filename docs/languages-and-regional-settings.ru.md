# Языки и региональные настройки

Dockstash поддерживает семь языков интерфейса. Язык выбирается автоматически при первом посещении, и вы можете сменить его в любой момент.

## Поддерживаемые языки

- English (`en`) — по умолчанию
- العربية (`ar`) — раскладка справа налево
- Français (`fr`)
- Deutsch (`de`)
- Español (`es`)
- Русский (`ru`)
- 中文 (`zh`)

## Как работает автоопределение

- **В браузере** мы читаем `navigator.language`. Если он совпадает с одним из семи языков (включая варианты вроде `ru-BY` → русский), используем его. Иначе — английский.
- **На сервере** мы разбираем заголовок `Accept-Language` (с учётом q-параметров), чтобы сообщения об ошибках, транзакционные письма и ответы API были локализованы. Явный заголовок `x-lang` или cookie `lang` имеют приоритет.

## Смена языка

Используйте переключатель **Язык** в навигации. Ваш выбор сохраняется в cookie `lang` на один год.

## Справа налево (RTL)

При выборе **العربية** мы устанавливаем `<html lang="ar" dir="rtl">` и весь макет отражается.

## Для разработчиков

- Переменная окружения `DEFAULT_LOCALE` (опциональная) задаёт язык сервера по умолчанию.
- См. `client/src/shared/i18n/README.md` и `server/src/shared/i18n/README.md`.
