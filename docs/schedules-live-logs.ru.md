# Расписания и живые логи

Dockstash запускает задачи backup / prune / check / drill по расписанию —
через сериализованную очередь, гарантирующую **одну задачу на репозиторий за
раз**.

## Типы расписаний

| Тип | Действие |
|---|---|
| `backup` | Стримит дампы БД + резервирует пути/конфиги. |
| `prune` | `restic forget --prune` с политикой удержания. |
| `check` | `restic check` — структурная целостность. |
| `drill` | Восстанавливает последний снапшот и сравнивает. |

## Одна задача на репозиторий

Два расписания, сработавшие одновременно для одного репозитория,
сериализуются. Разные репозитории работают параллельно. Prune — отдельный
тип, никогда не внутри backup.

## Удержание → `forget`

```
keepDaily/keepWeekly/keepMonthly → --keep-daily/--keep-weekly/--keep-monthly
```

## Живые логи

Каждая задача стримит stdout/stderr restic через Socket.IO на
`/scheduler`. Присоединяйтесь к комнате задачи с JWT — только к своим
задачам.

## Восстановление

После сбоя следующая попытка обнаруживает осиротевший лок и безопасно
вызывает `restic unlock`.
