# Использование панели

Dockstash — четыре экрана и одноразовый мастер настройки. У каждого экрана одно основное действие.

## Мастер настройки
1. **VPS-хранилище** — хост, пользователь, порт, приватный SSH-ключ.
2. **Пароль шифрования** — показан один раз. Немедленно скопируйте в менеджер паролей.
3. **Подтверждение** — поставьте галочку «Сохранил(а) — потеря = невозможность восстановления», после чего активируется **Готово**.

## Проекты
Каждая папка в `/var/www` появляется карточкой. Основное действие: **Копировать сейчас** с live-выводом restic.

## Детали проекта
Три вкладки в `?tab=`:
- **План** — файлы, БД, Traefik.
- **Расписание** — ежедневно / еженедельно / свой cron с inline-валидацией.
- **Тест восстановления** — статус последнего drill.

## Снимки
Выберите проект и точку восстановления, нажмите **Восстановить**. Диалог требует ввод точного имени проекта. По умолчанию — в новую папку; перезапись — явный опт-ин.

## Настройки
Три вкладки в `?tab=`: Хранилище, Хранение, Пароль шифрования.
