# التنبيهات والتدقيق والصحة

يعلن Dockstash عن الفشل بوضوح. أي فشل في نسخ احتياطي أو استعادة أو اختبار يرسل
بريدًا فوريًا (عبر Resend) لصاحب المشروع. كما يكشف heartbeat (مفتاح الرجل الميت)
عن التوقفات الصامتة — عندما لا يوجد خطأ ولكن لا يعمل شيء أيضًا.

## ما الذي يستدعي التنبيه

| النوع | متى |
|---|---|
| `backup` | فشل تشغيل نسخة احتياطية. |
| `restore` | فشل الاستعادة. |
| `drill` | فشل اختبار الاستعادة المجدول. |
| `heartbeat` | لم تنجح أي نسخة احتياطية خلال `ALERT_HEARTBEAT_HOURS` ساعة. |

يحمل كل بريد اسم المشروع والخطأ ووقت آخر نجاح ورابط لوحة التحكم. عند تعيين
`ALERT_WEBHOOK_URL` يتم إرسال الحمولة كـ JSON إلى ذلك العنوان أيضًا.

## نافذة heartbeat

يحدد `ALERT_HEARTBEAT_HOURS` (افتراضيًا `24`) عتبة التوقف الصامت. إذا كانت آخر
نسخة احتياطية ناجحة أقدم من هذه المدة، ينبه المسح مرة واحدة ثم يمنع التكرار
داخل نفس النافذة.

## سجل التدقيق

الإجراءات الحساسة أو المدفوعة تُضاف إلى سجل غير قابل للتعديل:
`backup.run`, `backup.restore`, `backup.delete`, `plan.change`.
كل قيد يسجل الفاعل والإجراء والهدف وIP والوقت.

جلب السجل: `GET /api/audit` (بحدود المالك، يتطلب تسجيل الدخول).

## نقاط الصحة والمقاييس

- `GET /api/health` — فحص جاهزية (200/503).
- `GET /api/metrics` — عدادات مجمعة.
- `GET /api/health/projects` — بحسب المشروع، بحدود المالك.

## متغيرات البيئة

| المتغير | الغرض |
|---|---|
| `RESEND_API_KEY` | مفتاح Resend. |
| `RESEND_FROM` | عنوان المرسل. |
| `ALERT_HEARTBEAT_HOURS` | عتبة التوقف الصامت. |
| `ALERT_WEBHOOK_URL` | Webhook اختياري. |
