# 使用仪表板

Dockstash 提供四个界面和一次性设置向导。每个界面都有一个主要操作。

## 设置向导
1. **存储 VPS** — 输入主机、用户、端口和 SSH 私钥。
2. **加密密码** — 只显示一次，请立即复制到密码管理器。
3. **确认** — 勾选"我已保存 —— 丢失将无法恢复仓库"以启用**完成**。

## 项目
`/var/www` 下每个目录显示为一张卡片。主要操作：**立即备份**，实时输出 restic 日志。

## 项目详情
三个标签，通过 `?tab=` 持久化：
- **计划** — 切换文件 / 数据库 / Traefik。
- **计划任务** — 每日 / 每周 / 自定义 cron，实时校验。
- **恢复演练** — 上次演练的状态。

## 快照
选择项目和恢复点，点击**恢复**。对话框要求准确输入项目名。默认恢复到新位置；覆盖需要显式选择。

## 设置
三个标签在 `?tab=`：存储、保留策略、加密密码。
