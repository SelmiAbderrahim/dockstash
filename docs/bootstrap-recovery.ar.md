# استرداد التمهيد

يغطي هذا الدليل سيناريو "اختفى VPS الإنتاج". يفترض أن ثلاثة أشياء فقط قد نجت:

1. **VPS التخزين** (مع مستودعات restic سليمة).
2. **`MASTER_ENCRYPTION_KEY`** (نسخة احتياطية خارج النطاق).
3. **مغلف تصدير الإعدادات** المحفوظ (`dockstash-export-*.json`).

بدون هذه الأشياء الثلاثة لا يمكن استرداد المستودعات — مغلف التصدير عديم
الفائدة بدون المفتاح الرئيسي، والمفتاح الرئيسي عديم الفائدة بدون مستودعات
التخزين المشير إليها.

## 1. إعداد وكيل جديد

جهز VPS إنتاج نظيف. استنسخ المستودع، املأ `.env`، وشغّل الكومة:

```bash
docker compose up -d
```

تبدأ خدمات `api` و`web` و`mongo` و`redis` و`docker-socket-proxy` مقابل Mongo
فارغ. لا يظهر أي مشروع بعد.

## 2. توفير نفس `MASTER_ENCRYPTION_KEY`

املأ `./secrets/master_encryption_key` بنفس المفتاح المطابق للبايت من الوكيل
القديم. لا تولد مفتاحًا جديدًا — كل نص مشفر في مغلف التصدير مربوط بهذا المفتاح.

## 3. استيراد مغلف التصدير

سجّل الدخول كأي مستخدم بنفس هوية المالك القديم، ثم أرسل POST لمغلف التصدير
المحفوظ إلى `/api/recovery/import`:

```bash
curl -X POST http://localhost:8080/api/recovery/import \
  -H "Authorization: JWT $TOKEN" \
  -H "Content-Type: application/json" \
  -d @dockstash-export-2026-07-01.json
```

يتحقق الاستيراد من شكل المغلف (`.strict()` zod)، ويرفض أي حقل يبدو كسر بنص
عادي، ويفك تشفير كل نص مشفر باستخدام مفتاحك الرئيسي. المغلف المُتلاعب به، أو
المغلف الذي لا يستطيع هذا الوكيل فك تشفير `keyVersion` الخاص به، مرفوض
بـ `HTTP 400`.

## 4. تأكيد وصول التخزين

بعد الاستيراد، يتم تشغيل `restic snapshots` مقابل كل مستودع مشروع باستخدام
كلمة المرور المفكوكة. الرد الأخضر يؤكد:

- إمكانية الوصول إلى VPS التخزين.
- فك تشفير كلمة المرور تحت `MASTER_ENCRYPTION_KEY` الحالي.
- عدم تلف المستودع.

## 5. الاستعادة

شغّل تدريب الاستعادة من لوحة التحكم أو عبر المُجدول. تستعاد اللقطات إلى مساحة
عمل مؤقتة ويتم فرقها ببايت/صف مقابل البيانات الوصفية المتوقعة.

## قاعدة الأشياء الثلاثة

**فقدان المفتاح الرئيسي أو رموز الاسترداد يجعل مغلف التصدير عديم الفائدة.**
يحمل المغلف فقط نصًا مشفرًا بـ AES-256-GCM. آمن للتخزين خارج الجهاز لأن نسخة
في الأيدي الخطأ عديمة الفائدة بدون المفتاح.

خزّن `MASTER_ENCRYPTION_KEY` ورموز الاسترداد على وسائط منفصلة، في مواقع مادية
منفصلة، وليس أبدًا في نفس النسخة الاحتياطية للمغلف.
