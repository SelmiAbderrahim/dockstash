# DM Outreach — Worked Examples

Filled, realistic renderings of `../dm-template.md` for different creator types and
situations — one case per file. Names/handles/videos in these files are **invented
examples of the right specificity**; before sending, every reference must be replaced
with a real artifact you actually consumed (checklist in `../dm-template.md`).

All program rules apply unchanged: single-use invite link, 30-day link expiry, honest
mechanics, FTC disclosure ask, max two follow-ups, never pay for coverage.

| File | Case | Channel |
|---|---|---|
| `youtube-homelab-creator.md` | Homelab YouTuber who admitted an untested backup script | YouTube business email |
| `x-indie-hacker.md` | Build-in-public indie hacker running prod on a VPS | X DM |
| `linkedin-agency-lead.md` | Agency technical lead hosting client sites | LinkedIn (connection note + DM) |
| `reddit-selfhosted-commenter.md` | r/selfhosted power commenter in a backup thread | Reddit (in-thread first, then DM) |
| `mastodon-selfhost-blogger.md` | Fediverse self-host blogger | Mastodon DM |
| `newsletter-author.md` | Self-hosting newsletter author (review, not ad) | Email |
| `devops-podcast-host.md` | DevOps podcast host (guest pitch, story-first) | Email |
| `reactive-data-loss.md` | Someone who *just* lost data — DO NOT PITCH case | Any |
| `inbound-question.md` | Warm inbound: someone DMs asking about Dockstash | Any |

## What varies by case (the point of these files)

- **The opener** always references *their* specific artifact — but what counts as an
  artifact differs: a video timestamp, a tweet, a care-plan page, a comment thread.
- **The differentiator sentence** flexes to their pain: untested script → drills;
  agency → fleet + flat pricing; indie hacker → free tier + own storage.
- **The offer** is the same (1 free year of Business, single-use link) except:
  reactive-data-loss (no offer at all) and inbound (they came to you — answer first).
- **The etiquette** is platform-law: Reddit punishes unsolicited DMs, Mastodon
  punishes growth-speak, LinkedIn strips links from connection notes.
