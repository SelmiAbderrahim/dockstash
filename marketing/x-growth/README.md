# X Growth — Program Guide

This folder is the complete playbook for promoting Dockstash on X (x.com) and growing
the founder's personal brand there. It distills three source playbooks — Brad Smith's
X Ads masterclass, the 0→5,000-followers organic framework, and the "hybrid method" AI
writing system (15K followers / 7.7M impressions) — into one Dockstash-specific
operating manual.

**This is a deep dive under `../07-social-content.md`, not a replacement for it.** Doc
07 owns X as a channel alongside Mastodon and LinkedIn: it sets the pillar mix, the
cadence, the UTM and disclosure rules. This folder inherits all of that and goes deep
on X-only mechanics (profile, daily engagement, the post bank, X Ads). Where the two
ever disagree, doc 07 wins — fix it here. All product facts trace to
`../01-positioning-and-icp.md` and `server/src/modules/billing/plans.ts`.

Sibling program: `../influencer-outreach/` (creator DM outreach + free-year invite
links; the X motion is `../influencer-outreach/x-dm.md`). That program feeds this one —
creators you build relationships with here are candidates for an invite link there.

## The one-paragraph strategy

People are not on X to buy things. They are there to learn, argue, laugh, and follow
people. So the play is: build a **personal brand** (people buy from people), use
**organic content + daily engagement** to earn trust, use **cheap Reach ads** (when
funded — see below) to pour fuel on posts that already work, capture attention with
**lead-magnet posts**, and let the sale happen later — in DMs, from the bio link, weeks
after the first touch. Success on X is measured in **quality followers**, not clicks.
The modern trust bar is roughly **24 touches across 3 platforms** before someone buys —
X is one of those platforms, and this playbook is how we rack up the touches for pennies.

## A note on the ads budget

The current plan (`../README.md`) funds Google Search, Reddit ads, and newsletters —
**there is no X-ads line.** The X Ads playbook (`06`) is written for when that money
exists: a Week-9+ test funded by reallocating the $100 Reddit line *only if Reddit
underperforms* against doc 11's $30 CAC ceiling. Until then, `01`–`05`, `07`, `08`, and
the swipe file are the whole program — organic X costs nothing but time and stands on
its own. Don't wait on a budget to start.

## The 90-day arc

**Weeks 1–2 — Foundation.** Fix the profile (`02`). Write and pin the pin tweet. Start
the daily comment routine (`03`). Build the Claude project + swipe file (`07`,
`swipe-file/`). Post 1–2x/day from the post bank (`05`). No ads (nor budget for them
yet) — the account needs organic posts and a coherent bio before X will treat ads well.

**Weeks 3–4 — Volume & launch.** Launch week aligns with doc 02 — post the recap
threads live. Keep posting and commenting daily; push toward 2–4 posts/day to find what
resonates. Run the first lead-magnet post (`04`, the `AUDIT` script). Still organic-only.

**Weeks 5–8 — Optimize organic.** Double down on the formats that outperformed (`04`
§5). Deepen the target-account relationships that feed the boost network (`03` §5).
Second and third lead magnets. Review weekly against `08`.

**Weeks 9–12 — Paid, maybe.** *If* Reddit has underperformed and the $100 was freed up
(`06` §0), launch the Top-of-Funnel Reach campaign with your best organic outliers as
creatives. Add MOF retargeting once TOF has warmed. The Bottom-of-Funnel ask (signup at
`dockstash.com`) comes last, when the audience has seen us ~6+ times. If Reddit is
working, skip all of this and keep compounding organic.

## Hard rules (carried from the outreach program — they apply here too)

- **Always disclose you built Dockstash.** The self-host crowd detects and punishes
  stealth marketing permanently. This one is not negotiable.
- **No fake scarcity, no invented deadlines.** Honest urgency only.
- **No buying engagement, likes, or followers.** Paid *reach* via the ads platform is
  fine; paid *fake social proof* is not.
- **Disclose material connections.** If we give someone something and they post, they
  disclose. If we post numbers, they're real numbers.
- **Report real metrics.** Screenshots come from the real product; stats in posts are
  genuine and current. A restore-drill screenshot showing a *failure* is fair game and
  honest; a mocked-up green dashboard is not.
- **No absolute claims.** We sell testing, not certainty. "Proves it restores" is the
  product's behaviour; "never lose data again" is a lie and a banned phrase.
- Source-playbook numbers quoted in these docs ($1,300 → 5,400 followers, 0.1¢/1K
  impressions, 7.7M impressions, etc.) are **benchmarks from the source creators**, not
  promises. Treat them as direction, not guarantees.
